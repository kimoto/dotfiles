# Session resume

**The end-of-session summary starts with the problem restated, not the diff**
(2026-08-09 user feedback; the four steps below are AI-drafted). Several sessions
run in parallel and hours pass between them — "what changed today" only reads to
someone who still remembers what was wrong.

Order: **restate the problem (what was this for) → symptoms (concrete objects and
numbers, no abstract words) → how far it got settled → one next step.**

⚠️ **Step 1's wording changes with the situation** — what felt off, what wasn't
understood, what had to be decided, what was broken, what needed measuring.
From 2026-08-09 to 2026-08-31 it was frozen as 「何が気持ち悪かったか」, an
AI-drafted noun stuck to that day's single incident, and it read wrong wherever
nothing felt "off". ★**Only the order is fixed; the noun is not.**

⚠️★**This is an order, not headings. Never print ①②③④ as labels** — found on
2026-08-31 by doing exactly that.

⚠️ Scope: the end-of-session summary. A brief whose context is continuous stays
diff-first.
