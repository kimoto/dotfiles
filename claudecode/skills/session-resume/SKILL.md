# セッションのまとめ方（久しぶりに戻ってきた人向け）

★**相手が前回を覚えているなら差分だけ。忘れているなら「何の話だったか」から。**
セッションに戻ってきた人は、忘れている側。
⚠️「今日変わったこと」から書くと、**覚えている人にしか読めない文章**になる。
差分が悪いのではなく、**順番**の問題。

## 順序

1. ★**何を解こうとしていたか**（ここで読み手が思い出す）
2. **何が起きていたか** — ★**物の名前と数字で**。⛔「効いていない」／✅「**`fetch` が 61秒。DB 610MB ＋ ログ 226MB を rsync していた**」
3. **どこまで片付いたか**（＋★**どこから先がまだ分からないか**）
4. **次にやること1つだけ**

⚠️★**1 の言い方は場面で変わる**（気持ち悪かった／分からなかった／決めたかった／壊れていた）。**決まっているのは順番だけ。**
⛔★**「① …」「② …」と見出しを立てない。**ラベルを並べると、**中身が空のままでも書けてしまう**。

## ★この4つだけだと落ちるもの

- ★**自分（AI）が間違えたこと・訂正したこと** — ⚠️ まとめは成果報告ではない。**直すときは前提ごと**（言い直しを3回並べない）
- ★**自分以外が動かしたもの** — 並行して動いている別のセッション、時間で動く処理。⚠️ 書かないと**自分がやったこと**として読まれる
- ★**返事待ちか、待たずに進めるか** — 読み手が**返事待ちのほうだけ**見れば済むように

## 残件（`wrapup` が集める。返すのはこの順で。⛔ 集めたものをそのまま並べない）

⚠️★**並べ替えるのであって、選別しない。全件出す。**「主なものは」で切ると、
落ちた1件は**誰も拾わない**。多いなら並べ方で読ませる。

1. ★**本人の返事が要るもの** — 一番上
2. **こちらが動かしたまま走っているもの** — ⚠️**セッションを閉じると止まるもの**は、そう書く
3. **手つかずだが、返事を待たずに進められるもの**
4. ⚠️**まだ決めていないこと**（🟡）— 決まったように書かない

⛔ 前置き・自己評価・やったことの列挙から始める／次にやることを何個も並べる／長く書く。
⚠️ 根拠は本人の実感が1件あるだけで、実験で確かめたものではない。**合わない相手には合わない。**
