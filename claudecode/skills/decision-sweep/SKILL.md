# 判断待ちの一括回収（集めて、Project にカードで並べ、各スレッドへ返す）

目的: **止まっている判断を一度で見渡し、ポチポチ押すだけで片付けられること。**
質問は各スレッドに散っている。**スレッドを開かずに押せる**ことが要点なので、カードは Project チャットに並べる。

★**Project チャット（コーディネーター）で動かす。**Project にカードを出せて、スレッドへ渡す `message_thread` を持つのはここだけ。
スレッドで頼まれたら、集めて一覧を返すところまでにして、カードは Project チャットで、と1行添える。

## 1. 集める

- `list_thread_sessions` を `next_cursor` が消えるまで読む。対象は `status_bucket` が
  `blocked` と `review_ready`
- `list_project_prs` の open / draft のうち、レビュー待ちのもの
- 各スレッドは `fetch_thread`（`newest_first`、数件）で**実際の質問文**を読む。
  ★タイトルや status だけで質問を書かない — 何を聞いているかは本文にしか無い
- ⚠️ 質問の後に本人がもう答えているものは外す（受け手がまだ動いていないだけ）
- `worker="disconnected"` や失敗で止まっているものは**判断待ちではない**。別枠で「止まっている」と書く

## 2. 並べる

最初に1行（「判断待ち N 件です。押してください」）、続けて**1件1枚**の `ask_decision` を Project チャットに出す。

- question の頭にスレッドの短い題、context にスレッドへのリンク `[短い題](#cmsg_…)` と質問の背景
- 選択肢2〜4、おすすめ1つ。スレッドのカードが既にあれば、その選択肢をそのまま写す
- ★**一語で選べない件**（「どう思う?」型）はカードにしない。最初の1行の下に、リンクつきの文章で並べる
- ⛔ **取り消せない操作**（本番変更・一括削除・外部への送信）はカードにしない。押した結果は
  コーディネーターの伝言としてしか届かず、受け手はそれを本人の承認として扱えない。
  リンクを並べて「これはスレッドで答えてください」と書く

## 3. 届ける

★**「閉じる / 続ける / 待つ」はコーディネーター自身で片付く**（`set_thread_resolved` など）。誰にも渡さずその場でやる。
迷うスレッドには選択肢に「確かめる」を入れ、押されたらコーディネーターが確かめてから閉じてよいか聞く。

それ以外は、押された wake ごとに `message_thread` でそのスレッドへ:「本人が Project のカードで X を選んだ（質問: …）」。
- 元のスレッドにも同じ質問のカードがあれば、受け手に `close_decision` で閉じるよう添える
- 押されなかったカードはそのまま残す。おすすめで勝手に進めない
- 解決済みのスレッドなら、開いた状態に戻ったか結果で確かめ、閉じたままなら `set_thread_resolved(false)`

文章で答えが来たら（「1A 2B」など）、`message_thread` の `context_message_ids` に**本人の答えのメッセージ ID** を入れ、
note には「N 番があなた宛て」と対応だけ書く。★原文の引用は本人の言葉として届く。

## 4. あと

各スレッドの返事はそれぞれのスレッドから来る。ここで結果を待って転記しない。

⛔ 定期実行（ルーチン）にしない。ルーチンは新しいスレッドとして走り、Project にカードを出せない。
