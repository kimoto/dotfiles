# 判断待ちの一括回収（集めて、1通で聞き、各スレッドへ返す）

目的: **スレッドを1つずつ開かなくても、止まっている判断を一度で片付けられること。**
質問は各スレッドに散っている。集めるのも聞くのも1回、答えは**それぞれのスレッドへ**戻す。

★**Project チャット（コーディネーター）で動かす。**答えを各スレッドへ渡せるのは
`message_thread` の `context_message_ids` だけで、これは本人の発言を**原文のまま**運ぶ。
⚠️ スレッドから `send_message` で渡した答えは peer の伝言で、受け手は本人の承認として扱えない。
スレッドで頼まれたら、集めて一覧を返すところまでにして、答えは Project チャットで、と1行添える。

## 1. 集める

- `list_thread_sessions` を `next_cursor` が消えるまで読む。対象は `status_bucket` が
  `blocked` と `review_ready`
- `list_project_prs` の open / draft のうち、レビュー待ちのもの
- 各スレッドは `fetch_thread`（`newest_first`、数件）で**実際の質問文**を読む。
  ★タイトルや status だけで質問を書かない — 何を聞いているかは本文にしか無い
- ⚠️ 質問の後に本人がもう答えているものは外す（受け手がまだ動いていないだけ）
- `worker="disconnected"` や失敗で止まっているものは**判断待ちではない**。別枠で「止まっている」と書く

## 2. 聞く（1通）

1件1行、番号つき。各行: スレッドへのリンク `[短い題](#cmsg_…)`、質問を一文、選択肢を短く、
★おすすめに印。末尾に答え方の例 —「`1A 2B 3おまかせ` のように返してください」。

- ★**一語で答えられる形にしてから出す。**「どう思う?」型は、選択肢に直すか、決められない理由を書く
- ⚠️ `ask_decision` は1枚1問。複数件をカードに分けて Project チャットに並べない。1件だけならカードでよい
- スレッドに `ask_decision` カードが既に出ている件は、そのカードへのリンクも添える
  （カードで押しても、この1通で答えても、どちらでも届く）
- ⛔ 取り消せない操作（本番変更・一括削除・外部への送信）を「おまかせ」に含めない。その件だけ明示の答えを求める

## 3. 届ける

本人の答え（1通）を受けたら、答えのあった番号ごとに:

- `message_thread` で該当スレッドへ。`context_message_ids` に**本人の答えのメッセージ ID**、
  note に「この答えの N 番があなた宛て、選択肢 X は〜」と対応だけ書く
- ★答えを言い換えて note に書くだけで済ませない。承認として効くのは原文の引用だけ
- 解決済みのスレッドなら、開いた状態に戻ったか結果で確かめ、閉じたままなら `set_thread_resolved(false)`
- 答えの無い番号は**そのまま残す**。おすすめで勝手に進めない

## 4. 返す

1行で: 何件届けたか、残った番号と、止まっていた（別枠の）スレッド。
各スレッドの返事はそれぞれのスレッドから来るので、ここで結果を待って転記しない。

⛔ 定期実行（ルーチン）にしない。ルーチンは新しいスレッドとして走り、`message_thread` を持たない。
