# 判断待ちの一括回収（集めて、一覧にし、各スレッドのカードで答える）

目的: **止まっている判断を一度で見渡し、ポチポチ押すだけで片付けられること。**
質問は各スレッドに散っている。集めて一覧にし、答えは**各スレッドのカード**で受ける。

★**Project チャット（コーディネーター）で動かす。**スレッドにカードを頼めるのは `message_thread` だけ。
⚠️ スレッドから `send_message` で渡したものは peer の伝言で、受け手は本人の承認として扱えない。
スレッドで頼まれたら、集めて一覧を返すところまでにして、カードを揃えるのは Project チャットで、と1行添える。

## 1. 集める

- `list_thread_sessions` を `next_cursor` が消えるまで読む。対象は `status_bucket` が
  `blocked` と `review_ready`
- `list_project_prs` の open / draft のうち、レビュー待ちのもの
- 各スレッドは `fetch_thread`（`newest_first`、数件）で**実際の質問文**を読む。
  ★タイトルや status だけで質問を書かない — 何を聞いているかは本文にしか無い
- ⚠️ 質問の後に本人がもう答えているものは外す（受け手がまだ動いていないだけ）
- `worker="disconnected"` や失敗で止まっているものは**判断待ちではない**。別枠で「止まっている」と書く

## 2. カードを揃える

★**答えは各スレッドのカードで押してもらう。**押した結果はそのスレッドに直接届くので、
誰も中継しない（中継すると、本人の承認として届く経路が `context_message_ids` しか残らない）。
⚠️ カードを Project チャットに並べない。そこで押されても届くのはコーディネーターで、
押した事実は引用できるメッセージにならず、スレッドへ承認として渡せない。

- カードが既に出ている件は、そのまま使う
- 出ていない件は `message_thread` でそのスレッドに頼む —「いま本人に聞きたいことを
  `ask_decision` カード1枚にして出して。1問・選択肢2〜4・おすすめ1つ」
- ★**一語で選べる形にならない件**（「どう思う?」型）はカードにしない。一覧で文章の質問として残す
- ⛔ 取り消せない操作（本番変更・一括削除・外部への送信）の件は、おすすめで先に進めないことをカードの context に書かせる

## 3. 一覧を出す（1通）

1件1行: スレッドへのリンク `[短い題](#cmsg_…)`、何を決めるかを一文、おすすめ。
カードの無い件は質問文をそのまま。末尾に「各スレッドのカードを押してください」と1行。

- カードを頼んだ件は、出たのを確かめてから一覧に入れる。まだなら「カード準備中」と書いて先に出す
- カードの無い件に一覧の返信で答えがあれば、`message_thread` で該当スレッドへ。
  `context_message_ids` に**本人の答えのメッセージ ID**、note には「N 番があなた宛て」と対応だけ書く。
  ★答えを言い換えて渡すだけで済ませない。承認として効くのは原文の引用だけ

## 4. あと

各スレッドの返事はそれぞれのスレッドから来る。ここで結果を待って転記しない。
押されないまま残ったカードは、次に頼まれた時の一覧にまた並ぶ。

⛔ 定期実行（ルーチン）にしない。ルーチンは新しいスレッドとして走り、`message_thread` を持たない。
