# 重い PC を軽くする

★**測ってから手を出し、手を出したら同じ測り方でもう一度測る。**一度に変えるのは1つだけ。
2つ同時に動くと、どちらが効いたのか分からなくなる（測っている間にアプリが勝手に終わった、なども含む）。

## 1. 測る

まとめて走らせる（読むだけ）:

- **CPU**: `bin/cpu_window.sh`（30秒の窓で、CPU 時間がどれだけ増えたかを見る）。
  ⚠️ `top` の瞬間値は使わない。同じ負荷でも 10〜55% の間で揺れる。
  ★重さの判断には **machine%** を使う。core% の 50 は 8 コア機なら 6% にすぎない。
  ⚠️ macOS の load average はスレッドの数を数えるので、20 を超えていても CPU の半分が空いていることがある。重さの指標にしない
- **メモリ**: `memory_pressure | tail -1`・`sysctl vm.swapusage`
- **ディスク**: `df -h /System/Volumes/Data`（使用率が 90% を超えると、OS の掃除や索引作成が増える）
- **熱・電源**: `pmset -g therm`・`pmset -g batt`・`pmset -g assertions | grep -i prevent`

`(new)` が付いた行は、測っている間に起動したプロセス。kill してもすぐ起動し直すデーモンは、ここに出る。

## 2. 原因を分ける（上から順に見る）

1. **並列で動いている Claude セッションのテスト**: `bats`・`tmux -S`・`lefthook` など。
   ⚠️ 他のセッションのものなので止めない。どのセッションのものかを名指しして本人に返す
2. **macOS のバックグラウンド処理**: `mediaanalysisd`（写真の解析）・`corespotlightd`・`mds_stores`（Spotlight）・
   `suggestd`・`photoanalysisd` など。どれも作業が溜まっているときだけ重い → 3 で優先度を下げる
3. **アプリ**: ブラウザの renderer（1つのタブ）や GPU プロセスなど。コマンドのパスまで見て、どのアプリかを特定する。
   Chrome のタブは PID からは引けないので、本人に Shift+Esc（タスクマネージャ）を開いてもらう
4. **メモリ・ディスクの余裕**: 空きメモリが少なく swap が増え続けている、ディスクが 90% を超えている。
   原因というより下地なので、数字を添えて伝えるだけ

## 3. 対処する

- **自分でやってよいこと**: `taskpolicy -b -p <pid>`。プロセスを E コアに寄せて、
  バックグラウンド扱いにする。戻すときは `taskpolicy -B -p <pid>`。
  プロセスが起動し直すと設定は消え、元に戻る
- ⚠️ **`renice` は使わない。**一度上げた nice は、root でないと元に戻せない
- ⚠️ **launchd のデーモンを kill しない。**すぐ起動し直して作業を続けることもあれば、
  `launchctl kickstart gui/$(id -u)/<label>` を実行するまで起動しないこともある
- **聞いてから**（`AskUserQuestion`、推奨を先に、戻し方を1行添える）: kill、アプリやタブを閉じる、
  本人が起動した `caffeinate` などを止める
- **管理者権限が要るもの**: 本人のターミナルで実行してもらう1行にして渡す。⚠️ AI から sudo しない
- **毎回起動して居座る常駐が原因のとき**: `machine-audit` に回す（止めるか残すかを記録する仕組みがある）

## 4. 測り直す

1 と同じ窓で `bin/cpu_window.sh` を走らせる。★対処したプロセスの machine% と、
全体の空き具合（`/usr/bin/top -l 2 -n 0 | grep 'CPU usage' | tail -1` の idle）の両方を見る。
⚠️ 下がっていても、同じ時間に別のものが終わっていたなら、どちらが効いたのか分からない。そう書く。

## 5. 返す

最初の一文で、何が重さの原因だったかを言う。続けて次の3つを書く。

- **やったこと**（戻し方を添える）
- **本人に頼みたいこと**（閉じてほしいタブ、渡した1行のコマンドなど）
- **時間が経てば消えるもの**（写真の解析など）

⚠️ 公開 repo には、PID・タブの URL・写真の枚数など、この Mac の中身を書かない。
